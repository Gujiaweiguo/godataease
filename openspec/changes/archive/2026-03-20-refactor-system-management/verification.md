## Test Cases

### TC1: 顶部菜单导航
```
Given: 用户已登录系统
When: 用户点击「可视化」下拉菜单
Then: 显示仪表板、数据大屏、模板管理三个选项
And: 点击任意选项可正常跳转
```

### TC2: 用户管理角色 Tab
```
Given: 用户进入「系统管理 > 用户管理」
When: 用户切换到「角色」Tab
Then: 显示角色列表
And: 可添加用户到角色
And: 可创建自定义角色
```

### TC3: 权限配置菜单权限
```
Given: 用户进入「系统管理 > 权限配置」
When: 用户选择「菜单权限」Tab
Then: 显示角色列表和菜单树
And: 可勾选菜单为角色授权
And: 保存后权限生效
```

### TC4: 权限配置资源权限
```
Given: 用户进入「系统管理 > 权限配置」
When: 用户选择「资源权限」Tab
Then: 显示资源树（数据源/数据集/仪表板/大屏）
And: 可为用户/角色分配资源权限
And: 支持查看/管理/授权/导出权限
```

### TC5: 权限配置行列权限
```
Given: 用户进入「系统管理 > 权限配置」
When: 用户选择「行列权限」Tab
Then: 显示数据集列表
And: 可配置行权限（按角色/用户/变量过滤）
And: 可配置列权限（禁用/脱敏）
```
